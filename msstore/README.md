# Пакеты для Microsoft Store

Версия от 24 ноября 2026 года, собрана из версии сайта 3.5.18.

```
packages/slovoplet.msixbundle          Windows 10 и новее
packages/slovoplet.classic.appxbundle  старые сборки Windows
screenshots/                           пять снимков 1920×1080
```

## Чем это отличается от APK

Внутри пакета **нет копии игры** — там адрес `https://5bukv.iluh.in`.
Windows открывает его в своём окне, без адресной строки, с иконкой в меню
«Пуск». Это та же PWA, которую можно поставить и вручную из Edge, только
завёрнутая в формат магазина.

Отсюда приятное следствие: новые выпуски игры доезжают до установленной
версии **сами**, без обновления пакета.

## Подпись

Пакеты не подписаны, и так и надо: приложения в Microsoft Store подписывает
сам Microsoft при публикации. Ключ, которым подписаны APK, здесь не
используется.

## Как собраны

Официальным сборщиком [PWABuilder](https://www.pwabuilder.com/) — тем, на
который ссылается документация Microsoft, — из адреса сайта и трёх значений
идентичности, выданных Partner Center.
