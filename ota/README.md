# Словоплёт beta: OTA 3.0 → 3.0.1

Этот канал отделён от стабильного main. База интерфейса — публичный релиз 2.7.2.
Идентификатор beta-приложения: `con.iluhin.fiveletters.beta` (как запрошено).
Ключ подписи APK — прежний ключ владельца; beta устанавливается рядом со стабильной игрой.

## Проверка на телефоне

1. Установите **slovoplet-beta-3.0.apk** из предварительного выпуска `beta-v3.0.0`.
2. Запустите игру с интернетом. Внизу — кнопка `β · Компоненты 3.0`; через
   несколько секунд она должна смениться на `β · Готова 3.0.1`.
3. Нажмите её. Окно покажет оболочку APK 3.0, компоненты 3.0 и готовую версию 3.0.1.
   Если проверка не началась сама, нажмите «Проверить обновления».
4. Завершите текущую партию, затем «Применить без установки APK». Можно вместо
   кнопки выйти из приложения кнопкой «Назад» с главной и открыть его заново.
   Простое сворачивание не перезапускает уже открытое поле.
5. Окно обновлений теперь должно показывать **оболочку APK 3.0, компоненты 3.0.1**
   и текст «Проверка OTA пройдена». Системного окна установщика не будет.
6. В настройках Android версия установленного APK останется **3.0** — это правильно.
   Закройте игру, отключите интернет, снова откройте: компоненты 3.0.1 сохранятся.

В выпуске `beta-v3.0.1` есть контрольный APK 3.0.1. **Для проверки OTA его ставить
не нужно**: он предназначен для чистой установки/сверки. Сначала тестируйте 3.0.

## Что обновляется

HTML, JavaScript, CSS, изображения и встроенный словарь. Нативные классы,
разрешения, иконка Android и ресурсы ОС требуют нового APK. Вложения Gemini
использованы как архитектурное описание, а не инструкции к окружению: вместо
целого ZIP загружаются отдельные компоненты по SHA-256. Для этой демонстрации
меняется один JSON-файл размером **152 байта**, девять файлов переиспользуются.

Манифест подписан RSA/SHA-256 ключом владельца. Открытый ключ закреплён в APK;
проверяются канал, applicationId, совместимость оболочки, версия, пути,
количество/размер файлов и SHA-256 каждого компонента. Загружать DEX/нативные
библиотеки через этот механизм нельзя. Приложение не запрашивает разрешение
на установку APK.

Файлы сначала сохраняются в отдельной папке во внутренней памяти, затем
включаются атомарным переключением указателя. Старая подтверждённая версия
остаётся доступна. Новая версия должна сообщить о завершении запуска; если
она не сделает этого за 30 секунд либо приложение закроется до подтверждения,
произойдёт откат. Повторная установка той же неудачной ревизии блокируется.
Повреждённый манифест/файл, ошибка загрузки и отмена не заменяют текущую версию.

Проверка/загрузка работает в фоновом потоке **пока приложение запущено**;
периодической загрузки при закрытом приложении здесь нет. Статус показывает
этап, а число файлов и байтов — по завершении загрузки. Партия автоматически
не прерывается. Сессия и API сохраняют исходный HTTPS-адрес игры.

## Формат канала

- `manifest.json` — подписанный указатель на актуальные beta-компоненты.
- `manifest-3.0.json`, `manifest-3.0.1.json` — снимки для проверки.
- `blobs/<sha256>.bin` — неизменяемые компоненты. Расширение/путь назначения
  находятся внутри подписанного манифеста, а не берутся из URL.

Самостоятельная правка JSON без переподписи не установится. Для следующего
обновления нужна новая версия/ревизия и подпись прежним ключом. Не меняйте
существующий blob: создавайте новый с именем по его SHA-256.

## Проверено и ограничения

Java-тесты: дельта, отложенное применение, подтверждение, откат после незавершённого
старта, повреждённые манифесты/компоненты и подтверждённая версия, неверная подпись,
SHA-256, пути, лимиты, канал, applicationId, совместимость оболочки, отмена.
Браузер: интерфейс обновления, отметка успешного запуска, продолжение игры,
блокировка ручного применения во время партии, мобильный и широкий экран.
APK скомпилированы и подписи проверены. Реальный Android/WebView и 30-секундный
watchdog в устройстве/эмуляторе здесь не запускались — это часть проверки телефоном.
Рабочий хостинг и стабильные main/релизы не менялись.
