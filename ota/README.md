# Совместимость OTA для APK 3.0 / 3.0.1

Разработка beta и её документация перенесены в
[app.slovoplet.beta](https://github.com/iluhin/app.slovoplet.beta).

Эта папка сохраняет подписанные снимки, открытый ключ и все компоненты,
которые нужны уже установленным APK с закреплённым старым origin.
Содержимое манифестов и blobs не менялось при переносе.
