# 3.0 beta — оболочка с обновлением компонентов

Основа — последний стабильный релиз 2.7.2 из main. Отдельный идентификатор
`con.iluhin.fiveletters.beta`, название «Словоплёт β», прежний сертификат владельца.

Установите этот APK первым. Он получит компоненты 3.0.1 из beta-канала без
системной установки APK. Появится кнопка «β · Готова 3.0.1»; завершите партию,
откройте её и нажмите «Применить без установки APK».

После обновления оболочка останется 3.0, компоненты станут 3.0.1. Добавлены
проверка подписи и хешей, отложенное применение и откат неудачного старта.
Нативные изменения всё ещё требуют APK. Загрузка работает при запущенной игре.

[Подробная инструкция](https://github.com/iluhin/app.slovoplet/blob/beta/ota/README.md).
Стабильный релиз не заменяется. APK подписан прежним ключом; на физическом
Android-устройстве в среде сборки не проверен.
