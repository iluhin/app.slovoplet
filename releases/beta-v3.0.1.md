# 3.0.1 beta — проверочное обновление компонентов

Эту версию должна увидеть beta 3.0. Меняется один компонент — файл с версией и
сообщением о завершении проверки OTA (**152 байта**). Остальные 9 файлов
используются повторно. В окне beta будет видно: «Оболочка APK 3.0 · Компоненты
3.0.1», а также сообщение «Проверка OTA пройдена».

Для теста **не устанавливайте контрольный APK 3.0.1 поверх 3.0**. Установите APK
из beta-v3.0.0, затем примените предлагаемые компоненты внутри игры. Контрольный
APK приложен только для чистой установки/сверки, ZIP компонентов — для просмотра.

[Инструкция, проверка офлайна и ограничения](https://github.com/iluhin/app.slovoplet/blob/beta/ota/README.md).
Манифест подписан ключом владельца. Публичный stable/main не изменены.
