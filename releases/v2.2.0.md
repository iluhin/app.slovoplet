# 2.2 — «Словоплёт»

Игра получила новое имя и новое лицо. «5 Букв» — самое занятое название в
жанре, «Словоплёт» свободен и говорит о сути: слова здесь плетут.

**Что нового**

- Новое имя и иконка: канат-узел с янтарной плиткой «С». Иконка адаптивная,
  поэтому круглая маска лаунчера больше не срезает канат.
- Окно обновления теперь в оформлении игры: текущая тема, размер файла
  по-человечески, список изменений и полоса загрузки прямо в окне.
- Сервер отдаёт заметки обо всех пропущенных версиях, а не только о последней.
- Тексты подсказок приходят с сайта: формулировки правятся без новой сборки.
- В окне «Как играть» видно версию приложения и сайта.
- В админке появилась минимальная версия: ниже неё игра предложит обновиться
  без кнопки «Позже», а сервер может вовсе не обслуживать старые сборки.

**Установка.** `versionCode 8`, minSdk 24, подпись прежним ключом — ставится
поверх 2.1.
