# 2.3 — новая иконка и порядок в имени

Версия 2.2 принесла новое имя, но хвосты остались: знак выглядел чужим,
прежнее «5 Букв» встречалось то на экране входа, то в настройках по
умолчанию, а само приложение называло сайту чужую версию. Всё это собрано
в одну версию.

**Версия приложения**

- Приложение верно сообщает сайту свою версию. Раньше сборка веб-части
  подставляла значение по умолчанию, игра представлялась версией 2.0, и
  обновление предлагалось снова и снова, даже когда стояла самая свежая.
- В окно обновления больше не сыплется вся история выпусков: сервер видит
  по `User-Agent`, что игрок уже читал.
- Если меняется только сборка, окно пишет «Техническое обновление».

**Рейтинг**

- Гостю под таблицей видно, почему его там нет и что профиль заводится за
  десять секунд, без почты.

**Иконка**

- Канат-узел крупнее и плотнее, нити уходят за край — знак читается даже в
  самом мелком размере.
- Иконка приложения, заставка, шапка игры, админка и фавиконка собраны из
  одного исходника.
- Маска лаунчера (круг, «капля», скруглённый квадрат) срезает только концы
  нитей: кольцо с плиткой остаётся целиком при любой из них.
- Знак в шапке больше не висит на чужом тёмном квадрате, а лёгкое
  покачивание ему вернулось.

**Имя**

- Заставка и экран входа складывают слово СЛОВО вместо прежних БУКВ.
- Прежнее «5 Букв» убрано отовсюду: с экрана входа, из настроек по
  умолчанию, из админки, подвала и документации.
- Экран входа берёт название и подпись из настроек сайта, а не из того, что
  было вшито в сборку.

**Окно обновления**

- Пункт, перенесённый на несколько строк, больше не обрывается на середине
  фразы.
- При одном пропущенном выпуске номер версии над заметкой не дублирует
  заголовок окна, а длинный заголовок не подлезает под крестик.

**Установка.** `versionCode 11`, подпись прежним ключом — обновление встанет
поверх установленной игры.
