# Частые вопросы

**Нужен ли аккаунт?**
Нет. Гостем можно играть сколько угодно. Профиль нужен только чтобы попадать в
общий рейтинг и видеть свою статистику с любого устройства.

**Нужна ли почта для регистрации?**
Нет: только имя и пароль. Почту игра не спрашивает и писем не шлёт.

**Что игра обо мне знает?**
Имя, которое вы сами выбрали, и статистику партий. Рекламы и трекеров нет,
разрешений приложение не просит.

**Почему игра не приняла моё слово?**
Оно не в словаре игры. Словарь пополняется — если слово точно существует,
напишите автору.

**Где «Ё»?**
Пишите «Е»: игра считает их одной буквой.

**Почему офлайн-партии не в рейтинге?**
Потому что без сервера нельзя проверить, как шла партия, а таблица общая.
Подробнее — [здесь](Offline).

**Почему нет слова дня без интернета?**
Оно одно для всех и живёт на сервере. Телефон загадал бы своё, и общий раунд
потерял бы смысл.

**Будет ли приложение для iPhone?**
Отдельного файла нет: собрать и подписать его можно только на Mac с платным
сертификатом Apple. Зато сайт ставится на домашний экран через «Поделиться» →
«На экран „Домой“» и играет без сети так же.

**Почему приложения нет в Google Play?**
Публикация требует отдельной учётной записи разработчика и проверки каждого
выпуска. Пока игра обновляется напрямую с сайта — быстрее и без посредников.

**Безопасно ли ставить APK с сайта?**
Файл отдаётся по защищённому соединению, приложение сверяет его контрольную
сумму и ставит системным установщиком. Все выпуски подписаны одним ключом, так
что обновление встаёт поверх прежнего. Берите файл только с
<https://5bukv.iluh.in/>.

**Сколько места занимает?**
Около 600 КБ.

**Какая версия Android нужна?**
7.0 или новее.

**Можно ли поставить игру на свой сайт?**
Да, она для этого и сделана: PHP 7.4+, папка с правами на запись, никакой базы
данных. Вопросы — автору.
